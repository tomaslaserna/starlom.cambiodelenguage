# Entregables de auditoría — Sistema V2

1. [Auditoría integral](./AUDITORIA_INTEGRAL.md): dictamen, evidencia, fortalezas, hallazgos, mapas y recomendación.
2. [Inventario actual](./INVENTARIO_ACTUAL.md): superficies, recorridos, fuentes y dependencias observadas.
3. [Matriz funcional](./MATRIZ_FUNCIONAL.md): conservar, adaptar, rediseñar, fusionar o retirar.
4. [Arquitectura objetivo](./ARQUITECTURA_OBJETIVO.md): dominios, datos, invariantes, autorización, integraciones y observabilidad.
5. [Pruebas y migración](./PRUEBAS_Y_MIGRACION.md): línea de base, matriz E2E, fases, rollback y puertas GO/NO-GO.
6. [Fase 1 — Administración y Finanzas](./FASE_1_ADMINISTRACION.md): alcance implementado, validación y pendientes de activación.

La vista ejecutiva navegable está disponible en `/system-v2/audit`. El prototipo y el informe usan datos locales ficticios; no escriben en producción.
